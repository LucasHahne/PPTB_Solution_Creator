Bridge table schema & naming

Conventions for M:N intersect tables in Solution Creator. Defaults are generated from the left and right tables; display and schema stay editable.

Naming defaults

Field Pattern Example (Student × Course) Editable
Display name Bridge {Left} {Right} Bridge Student Course Yes
Schema name Bridge{Left}{Right} BridgeStudentCourse Yes
Logical name (deploy) {prefix}{Schema} new_BridgeStudentCourse Prefix from publisher

Bridge table columns

Role Display Schema Notes
Primary Bridge Number BridgeNumber Autonumber · format BRG-{SEQNUM:5} (not a Name text column)
Lookup (left) {Left} Lookup{Left} Required lookup to left table (e.g. LookupStudent)
Lookup (right) {Right} Lookup{Right} Required lookup to right table (e.g. LookupCourse)

Deploy order (preview)

  1. Ensure left and right tables exist (project tables created earlier in the run).
  2. Create bridge table with autonumber primary.
  3. Create left and right lookup columns on the bridge (1:N from each side into the bridge).
  4. Publish customizations with the rest of the solution.

Native Dataverse N:N relationship metadata may be added later; v1 UX is the explicit bridge-table approach shown here.
